## Open questions / gotchas

- **Replay is not a new model evaluation.** It proves deterministic application
  behavior for captured responses. Prompt/model/output-contract changes
  invalidate request hashes and require a separate live capture later.
- Canonicalization is schema-aware: renumber only known ledger-generated IDs,
  then re-render through the real prompt builders. Never regex-replace
  UUID-looking text in serialized prompts.
- The persona script is the deterministic synthetic user. Owner labels are the
  independent answer key. Do not conflate them.
- Recordings, reports, generated artifacts, and unit-test fixtures have
  different ownership and commit policies; preserve the separation defined in
  the spec.
- `eval/out/` is already gitignored.
- `CLAUDE.md` is owner-managed. Slice 2 reaching its layout update is a hard
  owner-action gate.
- A future product UX idea was identified but is out of Phase 3 scope: show end
  users a consultation progress pipeline
  (`Describe → Review → Answer → Refine → Resolve → Confirm → Export`).
- The local Claude Code sandbox may deny local worker/port operations used by
  Next.js/Playwright. External owner runs are acceptable evidence when the
  exact command/output is reported. The Google Fonts dependency itself has
  already been removed.
